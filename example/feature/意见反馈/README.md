# 意见反馈

> ⚠️ 虚构示例，仅演示格式，不是真实需求。

## 是什么

让用户在应用内直接提交问题或建议，运营在后台集中处理并回复，替代原来的邮件反馈。

## 边界

- 包含：用户提交反馈、运营处理与回复
- 不包含：自动分类、工单派发
