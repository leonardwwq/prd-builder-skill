# 示例应用 v1.0 · 版本总纲

> ⚠️ **虚构示例，仅演示格式，不是真实需求，不构成任何业务规则。**
> 本文件由需求总控维护，页面会话只读。过程信息见同目录 `WORKLOG.md`（不进 Git）。

## 1 版本目标与范围

- 目标：让用户能在应用内提意见，运营能逐条处理并回复
- 包含：用户提交反馈、运营后台处理与回复
- 不包含：自动分类、自动派发、多语言

## 2 版本级决策

| D-00-02 | 页面上的时间一律按用户所在时区显示，精确到分钟 | 讨论确认 / 产品 | 01、02 |
